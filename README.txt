REQUIREMENTS:
- Windows 10 or 11
- Python (https://www.python.org/downloads/)
  IMPORTANT: Check "Add Python to PATH" during install

this folder contains the app source code

Use SETUP.bat and START_APP.bat to open it instantly

FIRST TIME SETUP:
1. Install Python 3.12
2. Double-click SETUP.bat (installs all packages)
3. Double-click START_APP.bat to run

EVERY TIME AFTER:
- Double-click START_APP.bat
